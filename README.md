# Репозиторий с лекциями по математическим дисциплинам.

**Приветствую!**
Пару дней назад, читая лекции по матану я решил: почему бы не переписывать лекции не в чистовую тетрадь, а на компьютер? Ведь это же удобнее и быстрее.


- Репозиторий разбит на каталоги. Структура каталогов следующая:
	Семестр $\rightarrow$ дисциплина $\rightarrow$ тема.

- Все файлы лекций написаны шрифтом семейства Computer Modern Serif (CMU Serif)

- Файлы разбиты по темам для удобства при заучивании определенных тем.

- Все лекции пишутся мной вручную при помощи программы Obsidian с плагинами: LaTeX Suite, Quick LaTeX, Underline и далее экспортируются в PDF.

- Лекции я пишу по мере наличия свободного времени.
